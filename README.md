# Programming Language Ecosystem

Welcome to the **ELP Project** repository\! This collection features three distinct applications, each developed using a major programming language from a different ecosystem: **Elm**, **Go (Golang)**, and **JavaScript (Node.js)**. This index serves to explore varied approaches to development, covering domains from **functional programming (using Elm)**, **concurrent server architectures (using Go)**, and the use of a **web language (JavaScript)** for console-based game logic.

For comprehensive details on setup, running instructions, and code architecture, please refer to the dedicated `README.md` file located within each project's directory.

| Project Directory | Technology | Primary Focus / Function | 
| :--- | :--- | :--- |
| **[elm/](https://github.com/fmaamoun/elp_project/tree/main/elm)** | Elm (Functional Front-End) | The primary goal was to explore a **functional programming language** for front-end web visualization. | 
| **[go\_project/](https://github.com/fmaamoun/elp_project/tree/main/go_project)** | Go (Backend/Server) | **Concurrent Computing System for All-Pairs Shortest Paths:** Engineered a concurrent Go client–server system to efficiently compute all-pairs shortest paths using Dijkstra’s algorithm on large graphs. |
| **[js/](https://github.com/fmaamoun/elp_project/tree/main/js)** | JavaScript (Node.js) | **JustOne (Console Game):** The goal was to use a **web language (JavaScript)** for console-based cooperative party game implementation. | 

> Note : ELP stands for "Écosystème des langages de programmation" in French, which translates to "Programming Language Ecosystem."
